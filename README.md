# Darts Pen Overlay — HONOR Magic V5

Android-app voor een **gewone capacitieve touchpen**, zonder speciale drivers of koppeling.

## Functies
- Transparante lijnen boven Darts Club
- Schakelaar **Tekenen / Spelen**; in speelmodus gaat de aanraking naar de game
- Rechte of vrije lijnen, kleur, dikte, ongedaan maken en wissen
- Automatisch opgeslagen lijnen voor het binnen- en buitenscherm, in staande en liggende stand
- Zwevende, verplaatsbare knoppen

## APK downloaden
Open **Actions** > **Build Android APK** > de laatste geslaagde run. Download onder **Artifacts** `DartsPenOverlay-APK`, pak ZIP uit en installeer `app-debug.apk` op je telefoon.

De APK is een debug-build, geschikt om handmatig te installeren. Sta indien gevraagd installatie vanuit je bestandenapp toe. Open daarna Darts Pen Overlay, verleen toestemming voor **Over andere apps weergeven**, start de overlay en open Darts Club.

**Let op:** Android en sommige games kunnen aanraakdoorgifte door overlays beperken. Deze app kan dat niet omzeilen. Een gewone touchpen wordt als een vinger gezien; er is geen palm rejection. De app is niet op een Magic V5 getest.
